# Changelog

## 1.0.0

- Weather: switch between all eight weather types, lock and release.
- Time: change the hour, freeze and release the clock.
- Vehicles: spawn by model name, from presets or from the history of the last eight spawns.
- Menu drawn in a separate transparent window, compatible with RTX Remix.
- Configurable keys and vehicle presets in `remix_trainer.ini`.
- Log file `remix_trainer.log`.
