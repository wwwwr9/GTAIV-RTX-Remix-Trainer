# Remix Trainer для GTA IV

Лёгкий трейнер для **GTA IV: The Complete Edition**, работающий вместе с **NVIDIA RTX Remix**.

Обычные трейнеры для GTA IV опираются на ScriptHook, загрузчики скриптов .NET или перехват Direct3D, чтобы
работать и рисовать меню, и под RTX Remix они перестают работать. Remix Trainer обходится без всего этого: это
один плагин `.asi` без внешних зависимостей, он не касается Direct3D, а меню рисует Windows в отдельном прозрачном
окне поверх игры — в кадры, которые захватывает и отрисовывает RTX Remix, ничего не добавляется.

[English version](README.md)

## Возможности

- **Погода** — мгновенное переключение всех восьми типов погоды, закрепление выбранной погоды или возврат
  управления игре.
- **Время** — смена часа, остановка времени суток и его возобновление.
- **Транспорт** — появление любой машины по имени модели, из настраиваемого списка заготовок или из истории
  недавно вызванных. Машина появляется в нескольких метрах перед игроком и смотрит в ту же сторону.
- Клавиши и список машин настраиваются в обычном файле `.ini`.
- Журнал, в котором видно, что именно найдено в исполняемом файле игры, — для быстрого поиска причин проблем.

## Требования

- GTA IV: The Complete Edition (32-битный `GTAIV.exe`).
- [Ultimate ASI Loader](https://github.com/ThirteenAG/Ultimate-ASI-Loader).
  Имя `d3d9.dll` занято RTX Remix, поэтому загрузчик ставится под другим именем, например `dinput8.dll`.
  Если загрузчик ASI уже установлен вместе с другим модом, больше ничего не нужно.
- Игра в **оконном** или **оконном без рамки** режиме. Меню находится в собственном окне поверх остальных, и в
  исключительном полноэкранном режиме оно может быть скрыто.

Сам RTX Remix не обязателен: без него трейнер работает так же.

## Установка

1. Скачайте `remix_trainer.asi` со страницы [Releases](../../releases).
2. Положите его в папку GTA IV (рядом с `GTAIV.exe`) либо в её подпапку `plugins` или `scripts`.
3. Запустите игру и загрузите сохранение. Меню открывается клавишей **F1**.

При первом запуске трейнер создаёт `remix_trainer.ini` рядом с файлом `.asi`.

Для удаления достаточно стереть `remix_trainer.asi`, `remix_trainer.ini` и `remix_trainer.log`.

## Управление

Клавиши по умолчанию (любую можно поменять в `.ini`):

| Действие | Клавиши |
| --- | --- |
| Открыть / закрыть меню | `F1` |
| Вверх / вниз | `Num 8` / `Num 2` или `↑` / `↓` |
| Изменить значение в первой строке страниц «Погода» и «Время» | `Num 4` / `Num 6` или `←` / `→` |
| Выбрать | `Num 5` или `Enter` |
| Назад (на главной странице закрывает меню) | `Num 0` или `Backspace` |

Клавиши читаются, пока меню открыто, но игра их тоже получает: если у клавиши есть действие в игре, игра на неё
отреагирует.

### Ввод имени модели

**Vehicles → Edit model** открывает строку ввода:

- вводятся буквы `A`–`Z` и цифры (верхний ряд и цифровой блок); `-` вводит `_`;
- `Backspace` стирает последний символ, а на пустой строке возвращает на страницу Vehicles;
- `Enter` или `Num 5` вызывают введённую модель;
- `Esc` или `Num 0` возвращают назад без вызова, введённое имя сохраняется.

Имя модели — до 24 символов. Клавиши, назначенные действиям меню, не вводятся.

## Меню

Пункты меню — на английском.

**Weather (погода)**

| Пункт | Действие |
| --- | --- |
| Current | Текущая погода; `←` / `→` переключают её |
| Next weather / Previous weather | Сразу переключают погоду |
| Lock weather | Держит выбранную погоду, пока не снят замок |
| Release weather | Снимает замок и возвращает погоду игре |

Типы погоды: `EXTRASUNNY`, `SUNNY`, `SUNNY_WINDY`, `CLOUDY`, `RAIN`, `DRIZZLE`, `FOGGY`, `LIGHTNING`.

**Time (время)**

| Пункт | Действие |
| --- | --- |
| Hour | Текущее игровое время; `←` / `→` или «Выбрать» меняют час, минуты не меняются |
| Lock time | Останавливает часы на показанном времени |
| Release time | Запускает часы снова |

Пока погода и время не закреплены, меню показывает значения самой игры.

**Vehicles (транспорт)**

| Пункт | Действие |
| --- | --- |
| Edit model | Ввод имени модели (см. выше) |
| Spawn typed model | Вызывает модель из строки ввода |
| Preset models | Список из `[Vehicles] Presets` в `.ini` |
| History | Последние восемь вызванных моделей, новые сверху |

Результат каждого действия на несколько секунд появляется строкой состояния под меню (или в левом верхнем углу
окна игры, если меню закрыто): выбранная погода или время, `Spawned: <модель>` либо ошибка, например
`Model failed to load: <модель>`, если такого имени модели нет или модель не загрузилась за 8 секунд.

## Настройка

`remix_trainer.ini` создаётся рядом с `remix_trainer.asi`:

```ini
[Keys]
ToggleMenu=112
Up=104
Down=98
Left=100
Right=102
Select=101
SelectAlt=13
Back=96
BackAlt=8

[Vehicles]
Presets=POLICE,TAXI,INFERNUS,TURISMO,SULTANRS,COMET,COGNOSCENTI,BUFFALO,AMBULANCE,FBI,FIRETRUK,NOOSE,NRG900,PCJ,ANNIHILATOR
```

- Значения в `[Keys]` — десятичные
  [коды виртуальных клавиш Windows](https://learn.microsoft.com/windows/win32/inputdev/virtual-key-codes):
  `112` = F1, `104` = Num 8, `98` = Num 2, `100` = Num 4, `102` = Num 6, `101` = Num 5, `13` = Enter,
  `96` = Num 0, `8` = Backspace. Стрелки работают всегда, в дополнение к `Up`, `Down`, `Left` и `Right`.
- `Presets` — имена моделей через запятую, регистр букв не важен. Если список пуст, используется список
  по умолчанию, показанный выше.

Изменения вступают в силу при следующем запуске игры. Подсказки в меню всегда показывают клавиши по умолчанию.

## Журнал

При каждом запуске создаётся `remix_trainer.log` рядом с `GTAIV.exe` (и копия рядом с `.asi`, если он лежит в
другой папке). Журнал перезаписывается при каждом старте.

| Сообщение | Значение |
| --- | --- |
| `remix_trainer initialized` | Всё найдено, меню доступно |
| `Game tick pattern not found` | Эта версия `GTAIV.exe` не поддерживается |
| `Native not resolved: …` | Не найдена нужная трейнеру функция игры; трейнер не включается |
| `Failed to create GDI menu overlay window` | Windows не создала окно меню |

## Если что-то не работает

- **Журнал не появляется.** Файл `.asi` не загружается: проверьте, что Ultimate ASI Loader установлен не под
  именем `d3d9.dll`, а трейнер лежит в папке игры, `plugins` или `scripts`.
- **Журнал заканчивается строкой `remix_trainer initialized`, но меню не видно.** Переключите игру в оконный
  режим или оконный без рамки.
- **`Model failed to load`.** Это не имя модели GTA IV. Нужны имена моделей (`SULTANRS`, `NRG900`), а не
  названия из игры (`Sultan RS`, `NRG 900`).

## Сборка из исходников

Нужна Visual Studio с нагрузкой **Разработка классических приложений на C++** (MSVC и Windows SDK).

Откройте `remix_trainer.sln`, выберите `Release | Win32` и соберите либо выполните в Developer PowerShell в папке
репозитория:

```powershell
msbuild remix_trainer.sln /p:Configuration=Release /p:Platform=Win32
```

Результат — `bin\Win32\Release\remix_trainer.asi`. Собирать нужно 32-битную версию (`Win32`): GTA IV —
32-битная игра.

## Как это устроено

- Плагин — обычная DLL с расширением `.asi`; Ultimate ASI Loader загружает её в процесс игры.
- На покадровое обновление игры ставится короткий перехват; место находится по байтовому шаблону в `GTAIV.exe`,
  поэтому трейнер работает в собственном потоке игры.
- Функции игровых скриптов (нативы) находятся при запуске по своим хешам в коде регистрации нативов, без
  жёстко заданных адресов конкретной сборки. Каждый вызов защищён: сбой пишется в журнал, а не роняет игру.
- Меню рисуется средствами Windows GDI в прозрачном, пропускающем щелчки окне поверх остальных, которое следует
  за окном игры. Вывод Direct3D 9 игры не затрагивается.

## Структура исходников

| Файл | Назначение |
| --- | --- |
| `src/dllmain.cpp` | Точка входа, поток инициализации, перехват обновления игры |
| `src/trainer.cpp` | Страницы меню, ввод, погода, время и транспорт |
| `src/overlay.cpp` | Окно меню на GDI |
| `src/native_invoker.*` | Поиск и вызов нативов |
| `src/memory.cpp` | Секции исполняемого файла, поиск шаблонов, правка кода |
| `src/config.cpp` | Чтение `.ini` и значения по умолчанию |
| `src/logger.cpp` | Журнал |
